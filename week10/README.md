# week10

My instrument is sort of a combination of a piano and a theremin. Each lever triggers the sound sample at a different rate. The sound loops so long as the state is 1. The user can move the mouse to change the pitch on the x-axis and the volume on the y-axis. I was inspired by my cat waking me up every morning and thought it would be fun to sample her meow so that I could annoy her back (it works).

I used the course LLM to debug and clean up interactions. Though I have used serial communication before, I have only used it between Arduino and Processing, so I used the LLM to help debug there as well.
